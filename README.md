# 课程资料整理工具 (Course Material Organizer)

一句话简介：一个计划用 Python 编写的命令行小工具，帮助用户按课程和日期高效整理学习资料，解决文件夹杂乱无章的问题。

## 项目状态
**开发中（当前处于设计阶段）**。当前版本暂无功能代码，正在完善需求分析与结构设计。

## 安装或获取
**当前为设计阶段，暂无安装包。**
未来计划通过 Python 包管理器安装：`pip install course-organizer`（计划中）。
你可以阅读本仓库的文档了解设计思路，或关注后续更新。

## 使用说明
**当前为设计阶段，暂无实际命令可执行。**
最小化操作预期：
未来用户将执行类似 `organizer sort --course "软件工程" --date today` 的命令，工具会自动将相关文件分类归档。
